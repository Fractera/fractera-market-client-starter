**What.**
- 3-1 (design pass, 75c3eb4): pages `admin/_pages/{recommendations,cart,purchases}`, islands `widget-dynamic-market-*` with skeleton,

- 3-2…4b (main pass, eb77e70, b9d3d1e), 4c (ec57435, the install by the core's contract): one branch door `admin/api/market` (GET `view`, POST `op`: search · choice · cart · get ·

  starter ordered before (`already-ordered`) takes its old order with no second payment. «Покупки» keep version, author, order and
  install state; «Установить ещё раз» reuses the order. The recommendations page gained the architect's own search field.
