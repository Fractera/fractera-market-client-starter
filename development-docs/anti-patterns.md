# Anti-patterns

Dead ends this element has already paid for. One entry per measured failure, newest on top: the symptom, the cause, the cure — and in
the cure, the sign that warns before the same failure comes again. An entry is written after a failure was measured, never as a
precaution: the template hands every new element this table empty.

| Symptom | Cause | Cure |
|---|---|---|
- 2026-11-27 · A door's shape learned by probing a purchase door made a real order (ord-be889…). Ask the core for a paying or ordering door's contract before calling it with valid input.
- 2026-11-27 · `npm run eyes --click` on a button whose request takes time proves nothing: the window closes before the fetch. Send the button's exact request to its door, and use eyes only to see the result.
